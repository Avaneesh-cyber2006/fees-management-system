Logo Generator Instructions

To create logo.png:

  1. Right-click on the logo above
  2. Select "Inspect Element" or "Inspect"
  3. Right-click on the logo element in the inspector
  4. Choose "Screenshot Node" or use browser screenshot tools
  5. Save as "logo.png" in: core/static/core/images/logo.png

Alternative: Use online tools like html-to-image converters
